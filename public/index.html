User Guide

Panduan singkat menggunakan Stock Hub

1. Upload Order

Upload file pesanan Shopee atau TikTok untuk memperbarui stok dari transaksi masuk.

2. Upload Product

Gunakan untuk menambah atau memperbarui data master produk dan SKU.

3. Update Status

Upload file khusus untuk mengubah status produk, misalnya ACTIVE atau INACTIVE.

4. Upload Adjustment

Pilih Restock atau Set Stock, lalu upload file untuk menyesuaikan jumlah stok.

5. Multi SKU Processor

Gunakan untuk cek stok, restock, sales, set stock, atau update status beberapa SKU sekaligus.

6. Download Export

Unduh file pembaruan stok untuk Shopee atau TikTok Shop.

7. Search dan Activity

Cari SKU, nama produk, atau barcode dari kolom pencarian. Gunakan View All untuk melihat detail seluruh aktivitas.
